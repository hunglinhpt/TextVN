# R2-175 — Fcitx5 5.0.x giữ Ctrl+Shift: `textvn doctor` cảnh báo (claude-opus-c4c5a567)

## VI

- **Sửa lỗi (Linux, Fcitx5)**: trên **Ubuntu 22.04, Linux Mint 21, Debian 12** (Fcitx5 5.0.x), Fcitx5 mặc định gắn
  **Ctrl+Shift** vào *Enumerate Input Method Forward/Backward* nên phím này chỉ đổi bộ gõ sang `keyboard-us` — công tắc
  V/E của TextVN không chạy, biểu tượng và trạng thái không đổi, các ứng dụng khác không đồng bộ. `textvn doctor` (và
  gói chẩn đoán 1 chạm) nay báo **`W_CTRL_SHIFT_TAKEN`** — cùng mã với Windows (G22) — kèm cách trả phím lại cho TextVN
  (`fcitx5-configtool` → Tuỳ chọn chung → xoá phím Enumerate Forward/Backward) hoặc dùng **Ctrl+Shift+Space**. TextVN
  không tự sửa cấu hình Fcitx5 của người dùng.
- Phát hiện bằng CI Linux ARM64 mới (ARM-L1, `ubuntu-22.04-arm`): chẩn đoán `fcitx CurrentInputMethod=keyboard-us` sau
  Ctrl+Shift. Cấu hình phím tắt của phiên test Fcitx5 nay ở MỘT tệp `scripts/lib/fcitx5-test-env.sh` cho cả 3 script.

## EN

- **Fix (Linux, Fcitx5)**: on **Ubuntu 22.04, Linux Mint 21, Debian 12** (Fcitx5 5.0.x), Fcitx5 binds **Ctrl+Shift** to
  *Enumerate Input Method Forward/Backward* by default, so the key only switches the input method to `keyboard-us` —
  TextVN's V/E toggle never runs, its icon and state stay unchanged, other apps do not sync. `textvn doctor` (and the
  one-click diagnostic bundle) now reports **`W_CTRL_SHIFT_TAKEN`** — the same code as on Windows (G22) — with how to
  give the key back to TextVN (`fcitx5-configtool` → Global Options → clear Enumerate Forward/Backward) or use
  **Ctrl+Shift+Space**. TextVN does not edit the user's Fcitx5 configuration.
- Found by the new Linux ARM64 CI (ARM-L1, `ubuntu-22.04-arm`): diagnostics showed `fcitx CurrentInputMethod=keyboard-us`
  after Ctrl+Shift. The Fcitx5 test-session hotkey config now lives in ONE file `scripts/lib/fcitx5-test-env.sh` for all 3 scripts.
