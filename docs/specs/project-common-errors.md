# Project Common Errors — Sổ lỗi chung toàn dự án

> **Mục đích (G3 — `../00-WORKFLOW.md`):** Ghi nhận các lỗi lập trình, công cụ, cú pháp, CI, git đã gặp và fix thành công.
> ID dạng `E{n}` liền mạch, không xóa entry.

## 1. Danh sách lỗi (E-IDs)

| ID | Hiện tượng (dán nguyên thông báo lỗi) | Nguyên nhân | Fix |
|---|---|---|---|
| E1 | `UnicodeEncodeError: 'charmap' codec can't encode character...` khi chạy `reuse lint` trên Windows console | Môi trường Windows cmd/powershell mặc định dùng code page ANSI (cp1252), Python stdout ném ngoại lệ khi in ký tự tiếng Việt | Set biến môi trường `$env:PYTHONUTF8 = "1"` và `$env:PYTHONIOENCODING = "utf-8"` trước khi gọi `reuse lint` qua script `.ps1` |
| E2 | `reuse lint` báo lỗi `Missing licenses: ...` hoặc `Invalid SPDX Expression` do nhầm lẫn scanner | Viết literal chuỗi định dạng SPDX header trong phần doc-comment hoặc prose markdown khiến scanner của REUSE quét nhầm thành header thật bị hỏng | Diễn đạt gián tiếp, không viết nguyên văn chuỗi nhận dạng SPDX trong comment; hoặc bọc `<!-- REUSE-IgnoreStart -->` |
| E3 | `error: unexpected closing delimiter: '}'` ở `adapters\windows-hook\src\lib.rs:118:1` | Dư dấu ngoặc nhọn `}` ở hàm `empty_result()` (dòng 117) | Xóa dấu `}` thừa, chạy `cargo fmt` để chuẩn hoá thụt lề |
| E4 | `error[E0432]: unresolved import 'windows::Win32::Foundation::BOOL'` | Trong crate `windows 0.61`, `BOOL` được đặt trong `windows::core::BOOL` (re-export qua `windows_core`), không nằm ở `Win32::Foundation` | Sử dụng `windows::core::BOOL` hoặc `use windows::core::*;` |
| E5 | `error[E0599]: no method named 'query' found for struct 'Com::IClassFactory' in the current scope` | Trait method `query` của COM interface thuộc trait `windows::core::Interface`, cần đưa trait vào scope | Thêm `use windows::core::Interface;` hoặc `use windows::core::*;` |
| E6 | `error[E0308]: mismatched types: expected Result<&ITfContext, Error>, found Option<_>` | Helper method `.ok()` trên wrapper `Ref<'_, T>` của `windows 0.61` trả về kiểu `Result<&T, windows_core::Error>`, không phải `Option` | Pattern match `Ok(c)` / `Err(e)` thay vì `Some(c)` / `None`, hoặc dùng toán tử `?` |
| E7 | `error[E0610]: u32 is a primitive type and therefore doesn't have fields` khi dùng `TF_MOD_CONTROL.0` | Trong crate `windows 0.61`, các hằng số modifier TSF `TF_MOD_CONTROL` và `TF_MOD_SHIFT` là kiểu số nguyên `u32` trần, không phải struct newtype | Dùng trực tiếp toán tử bitwise `TF_MOD_CONTROL \| TF_MOD_SHIFT` thay vì `.0` |
| E8 | `error: this public function might dereference a raw pointer but is not marked unsafe` (clippy `not_unsafe_ptr_arg_deref`) | Phương thức COM interface sinh ra bởi `#[implement]` như `OnPreservedKey(..., rguid: *const GUID)` nhận raw pointer nhưng method signature của trait không có từ khóa `unsafe` | Kiểm tra con trỏ `!rguid.is_null()` trước khi deref trong `unsafe` block, và đặt `#[allow(clippy::not_unsafe_ptr_arg_deref)]` kèm chú thích `// SAFETY:` |
| E9 | `error[E0432]: unresolved import 'textvn_tray::icons::load_app_icon'` trên **ubuntu CI** (clippy/test trên Windows đều xanh) | Move/call hàm Win32 (`#[cfg(windows)]`) qua module dùng chung mà import/call ở side không cfg-gate — crate vẫn phải build trên Linux cho gate `--workspace`; clippy trên host Windows không nhìn thấy nhánh cfg-out | Import/call hàm cfg(windows) phải `#[cfg(windows)] use …;`; **gate mới (Checklist A, release-process.md): `cargo check --workspace --exclude textvn-win-hook --all-targets --target x86_64-unknown-linux-gnu` trên host Windows bắt được lỗi này trước push** |
| E10 | Commit message mất từng đoạn lệnh trong backtick (dòng trống giữa chừng) khi `git commit -m "…`cmd`…"` qua Git Bash | Bash thực thi command substitution `` `…` `` TRƯỚC khi truyền `-m` — nội dung backtick biến thành output của lệnh (thường rỗng) | Viết message vào file rồi `git commit -F <file>`; hoặc thoát `\\`` — không inline backtick trong `-m` qua shell |
| E11 | `error[E0061]` ở `tray/src/menu.rs` và `error[E0433]: cannot find crate windows` trên Linux/macOS CI sau khi Windows test xanh | Nhánh non-Windows có chữ ký `uninstall()` cũ; `windows` dependency chỉ có ở `cfg(windows)` nhưng import/worker IPC không được gate | Đồng bộ stub non-Windows với lời gọi mới, gate toàn bộ Windows API và worker bằng `#[cfg(windows)]`; chạy `cargo check` **và** `cargo clippy --all-targets -D warnings` với target Linux/macOS trước push |
| E12 | Swift macOS: `'kCFRunLoopDefaultMode' has been renamed to 'CFRunLoopMode.defaultMode'` | SDK Swift mới đổi tên hằng CoreFoundation trong Swift overlay; Windows chỉ parse được cú pháp, không typecheck AppKit | Dùng `CFRunLoopMode.defaultMode`; giữ CI Swift hai kiến trúc và xuất compiler error ra check-run annotation. Nếu log đi qua `tee`, phải `set -o pipefail` để không che mã lỗi |
